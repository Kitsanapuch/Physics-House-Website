# Physics Plus Website

ระบบเว็บไซต์ร้านสอนพิเศษ Physics Plus สำหรับนักเรียน ครู และผู้ดูแล พัฒนาบนกิ่ง `DevTutor` ก่อนนำขึ้นใช้งานจริง

- [คู่มือติดตั้งบน Vercel](DEPLOY.md)
- [คู่มือ Google Sheet ค่าจ้างครู](SHEET_GUIDE.md)

ระบบเริ่มด้วยคอร์ส 8 วิชาตามระดับ ม.ต้น/ม.ปลาย ผู้ดูแลเปลี่ยนราคาและจัดครู ห้อง เวลาเองทั้งหมด เมื่อนักเรียนสมัครคอร์ส ผู้ดูแลออกใบแจ้งยอดและยืนยันการรับเงิน ระบบจึงสร้างใบสำคัญรับเงิน PDF ที่ผูกกับคอร์สและรายการชำระ นักเรียนดาวน์โหลดได้ในหน้า “การชำระเงิน” ของตน

ก่อนเปิดรับข้อมูลจริง ให้ตั้งค่าฐานข้อมูลและอีเมลฝั่งเซิร์ฟเวอร์ตามคู่มือ ตลอดจนทดสอบสิทธิ์และการทำงานบนระบบที่ deploy แล้ว ไฟล์ `.env.example` เป็นเพียงตัวอย่างชื่อค่าที่ต้องตั้ง; อย่า commit ไฟล์ที่มีรหัสหรือ token จริง
